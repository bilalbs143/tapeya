# Shared cross-repo artifacts

Files here are consumed by **api/** (PHP) and **app/** (JS). Neither sub-project owns this tree alone.

## Graphics broadcast stack

| Path | Role | Generated by |
|------|------|--------------|
| `graphics-command-manifest.json` | Command catalog (type, category, processorId) | `php artisan graphics:export-manifest` |
| `graphics-themes.json` | Registered broadcast graphics themes | Hand-edited |
| `graphics-core/` | Processors, normalizers, domain logic | Hand-edited (+ `graphicCommandKeys.js` from artisan) |

**JS import:** `@tapeya/graphics-core/*` (graphics build only — consumer SPA must not import it).

**PHP export:** `api/app/Console/Commands/ExportGraphicCommandManifest.php` writes both manifest JSON and `graphics-core/src/graphicCommandKeys.js`.

**CI:** `scripts/check-graphics-drift.js` + `.github/workflows/graphics-checks.yml` manifest-export job.
